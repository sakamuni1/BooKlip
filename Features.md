# BooKlip Features

BooKlip is a local-first productivity app for macOS that keeps the text, images, files, and notes you use throughout the day organized and easy to find.

## Capture everyday items

- **Clipboard history:** Automatically save copied text, links, images, and files while clipboard monitoring is enabled.
- **Screenshots:** Capture a selected area or window and keep the result with your other items.
- **Downloads:** Watch the Downloads folder and add newly downloaded files to BooKlip.
- **Voice memos:** Record audio, play it back, and create transcripts with speech recognition.
- **Notes and code:** Keep notes, code snippets, and other useful text close at hand.

## Organize with tabs and groups

- Create tabs for projects, clients, or different workflows.
- Arrange tabs into named groups and move items between tabs.
- Pin important items so they stay easy to reach.
- Protect individual tabs with a password.
- Restore items moved to the Trash using deleted-item recovery.

## Search across your collection

- Search text, links, filenames, and saved snippets.
- Search across all tabs from the main search field.
- Start a query with `#` to search only the current tab.
- Sort and filter items to narrow down long histories.

## Preview and edit files

### Images

- Preview images with zoom and pan controls.
- Crop, rotate, and flip images horizontally or vertically.
- Add brush marks, rectangles, circles, arrows, and text annotations.
- Changes are saved to the image.

### Documents and text files

- Preview supported documents, including PDFs and text-based files.
- Edit text-based documents and code files in BooKlip, including Markdown, JSON, CSV, HTML, CSS, and common programming-language files.
- Save edits to the original file. BooKlip creates a backup of the previous text before saving.

### Audio and video

- Play audio and video from the item preview.
- Record and review voice memos without leaving BooKlip.

## Browse folders in one or two panels

- Open a folder in a dedicated preview window.
- Browse with a single panel or compare two folder locations side by side.
- Switch between grid, large-list, compact-list, and metadata list layouts.
- Keep frequently used locations in the sidebar and save folder layouts for later.
- Drag files between panels and open items in their associated apps.

## Work with other apps

- Drag and drop items between BooKlip and other apps.
- Copy saved items back to the clipboard.
- Share selected files through macOS AirDrop.
- Export and import item data for backup or migration.

## Extract text from images

Use OCR to recognize text in screenshots and images, then copy or save the extracted text for searching and reuse.

## Privacy by default

- BooKlip stores your collection on your Mac by default; no account is required.
- Clipboard content and local files are not sent to BooKlip servers.
- BooKlip does not include third-party advertising or analytics.
- BooKlip connects to GitHub to check for public announcements. That request does not include your clipboard items or files.
- Screen capture, microphone, and speech-recognition access are used only for the features that need them.
